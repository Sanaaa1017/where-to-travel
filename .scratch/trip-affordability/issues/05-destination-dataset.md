# 05 — 20 國真實資料

**What to build:** 把種子資料換成一份涵蓋 20 個國家的資料集，讓 Traveler 看到的是一份真正有參考價值的清單，而不是幾個示範用的假國家。

**Blocked by:** 02

**Status:** ready-for-agent

國家範圍：日本、韓國、香港、泰國、越南、新加坡、馬來西亞、菲律賓、印尼、美國、加拿大、澳洲、紐西蘭、英國、法國、德國、義大利、西班牙、荷蘭、土耳其。

**關於數字的來源，這張票必須誠實處理。** 沒有免費且可自由散布的各國旅遊花費資料集（Numbeo、Budget Your Trip 限制再散布，公開的歷史票價資料則根本不存在）。因此這一版的數字是**未經查證的估算**，不是查來的。這一點必須寫在檔案裡，不能只存在於這張票。

- [ ] 20 個 Destination 齊備，每個含機票、每晚住宿、每日花費、單程飛行時數
- [ ] 金額單位一律 TWD
- [ ] 檔案開頭註明產生日期，並明確標示數字為未查證估算
- [ ] 資料完整性檢查：id 唯一、所有數值為正數
- [ ] 該檢查是唯一 import 真實資料的測試，行為測試仍使用自備 fixture
- [ ] 飛行時數需合理反映實際航程，因為它會決定 Minimum Stay
- [ ] 數字準確度目標為量級正確即可，不追求精確
