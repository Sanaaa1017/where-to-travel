# 09 — 地球儀 / 地圖視覺化

**What to build:** 除了清單之外，讓 Traveler 在地球（或地圖）上看到自己去得起哪裡——去得起的國家與差一點的國家用不同顏色標示。

「出國逃離」這件事本身是有畫面的，一份表格傳達不了。這張票要補的是那個畫面。

**Blocked by:** 05

擋在 05 之後是刻意的：要先有 20 國的真實資料，才看得出視覺化實際長什麼樣，也才有足夠依據決定要地球儀還是平面地圖。在只有 3 個種子國家的階段做這個判斷會判斷錯。

**Status:** ready-for-human

**已決定：地球儀（react-globe.gl）。** 由使用者拍板，理由是情緒感——「出國逃離」要的就是轉動地球那個畫面，一眼看完所有國家不是這個產品的重點。地球因此成為進站第一眼的主角，清單退成右側欄。體積代價（three.js）接受。

國家輪廓取自 Natural Earth 1:110m（公有領域），已裁成 `src/data/countryOutlines.ts`（只留 ISO alpha-2 與繁中名稱，座標取兩位小數，約 160 KB）。Destination 的 id 就是輪廓的 ISO 代碼。

- [x] 決定地球儀或平面地圖，並記錄選擇的理由
- [x] Affordable 與 Shortfall 的 Destination 以不同顏色區分
- [x] 點選一個國家能看到它的 Trip Cost 或 Shortfall（滑過看金額，點清單把地球轉過去）
- [x] 假期不足而被排除的國家不高亮，與清單的行為一致
- [x] 視覺化為清單的補充而非取代——清單仍是比較金額的主要方式
- [x] 手機上可用，不因此犧牲 08 的成果（窄螢幕時清單改為下半部面板）
- [x] 不得為了視覺化而把邏輯搬進 UI 層，`planTrips` 維持唯一接縫

**留給 05 的坑：** Natural Earth 110m 沒有新加坡與香港的輪廓（面積太小）。資料集擴到 20 國時，這兩個 Destination 會出現在清單裡但不會在地球上亮起來，需要另外處理（換 50m 輪廓，或改用點標記）。
