# 08 — 手機可讀版面

**What to build:** 讓這個網站在手機上好用。

會用這個產品的情境很具體：凌晨一點、躺在床上、突然又想逃走。那個當下手邊的是手機，不是筆電。桌機版能用但手機版難讀的話，這個產品等於在最常被想起的時刻缺席。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 小螢幕下兩個輸入欄好按、不需縮放
- [ ] 兩個區塊在窄版下依然能一眼分辨
- [ ] 清單每筆在窄版下不擠壓、不橫向捲動
- [ ] 金額在小螢幕上仍清楚易讀
- [ ] 數字輸入欄在行動裝置上會叫出數字鍵盤
