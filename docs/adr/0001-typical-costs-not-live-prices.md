# 用典型行情估算 Trip Cost，不查即時票價

這個產品要解決的是「我到底能不能走」的模糊焦慮，而不是幫人訂票，所以 Traveler 不需要輸入出發日期：我們用各 Destination 的典型/平均花費估出 Trip Cost，輸入完當下就給出可行清單。

## Considered Options

- **即時票價 API** — 最準確，但需要 Traveler 先想好日期（正是「一想到準備就累」的那道門檻），且幾乎必然需要後端與付費 API。
- **典型行情（採用）** — 精確度較低，但零門檻、可純前端、答案即時。對「先讓我知道能不能走」這個目的來說，準確到「量級正確」就足夠了。

## Consequences

- Trip Cost 是**估算值**，不是報價。介面必須誠實呈現這一點，不能讓 Traveler 誤以為那是可成交的價格。
- 沒有日期概念，因此淡旺季價差不會反映在結果裡。
- MVP 不需要後端。
